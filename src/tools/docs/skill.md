<!-- brief -->
Invoke a skill by name to load its full instructions. Skills are reusable prompt expansions for specific task types; the available skills are listed in the system prompt under "Available Skills". Pass context via the `arguments` parameter.

<!-- guide -->
Invoke a skill by name to load specialized instructions. Skills are reusable prompt expansions for specific task types. The available skills are listed under *Available Skills* in this prompt. Pass context via the `arguments` parameter.

After installing, editing, or removing a skill, call `reload` to apply changes.
